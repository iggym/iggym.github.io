How these are made

Same rules as the homepage: hand-written HTML, CSS, and a little JavaScript, no build step and no framework. They work without JavaScript and follow your light or dark setting. This index counts anonymous page views with Cloudflare Web Analytics, which doesn’t use cookies. Each subject site lives in its own repository, so the source link on a card takes you to that code. This page doesn’t describe analytics on those other sites.

If one of them is useful — or hard to read on your device — I’d like to hear about it. The contact links are on the homepage.
