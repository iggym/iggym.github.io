Claude Context Engine

Paste messy context, such as logs, code dumps, config files, or meeting notes, and get back a tighter prompt that’s ready to give Claude or another assistant. A hosted AI model does the rewriting.

Sends text to a server

Avoid pasting passwords, API keys, or private data. Common secrets and personal details are masked automatically, but check the preview. When you press Rewrite, your text is sent to a server I run, which passes it to a hosted AI model. If you need everything to stay on your device, use Context Extractor or Prompt Matrix Evaluator.
