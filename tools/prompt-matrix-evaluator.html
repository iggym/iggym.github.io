Prompt Matrix Evaluator

Paste a prompt and this page removes common filler, like “could you please” or “make sure to”, then shows the estimated token count before and after. It doesn’t call an AI model or judge whether your prompt is good.

Stays on your device

How to use it
  1. Type or paste your prompt in the box.
  2. Check the highlighted phrases in “What was removed”. Only filler is cut, never your actual request.
  3. Copy the tightened version and use it wherever you were going to send the original.

Token counts are estimates (about four characters per token). Real counts vary by model.
