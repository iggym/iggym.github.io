Plan what goes into a model’s context window before you ship. Paste each part of a request, or just enter its size: system prompt, tool definitions, retrieved documents, chat history, and the question. See whether the reply still fits, what each request costs, and what to trim first.

How to use it
  1. For each section, paste real text or type an approximate token count. Use counts for things like long histories you don’t want to paste.
  2. Set the window size and price for the model you use. Check your provider’s current numbers.
  3. Read the advice. It points at the biggest section and the cheapest fix.
