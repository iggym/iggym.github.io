Prompt Diff & Stager

Compare an old and a new version of a prompt word by word, fill in any {{placeholders}}, and copy the finished prompt. Save snapshots as you go so you can come back to a version that worked.

Stays on your device Remembers your work

How to use it
  1. Paste the version you’re starting from in Before and edit your new version in After.
  2. The comparison shows added words underlined in green and removed words struck through in red.
  3. Write {{name}} anywhere in the new version to get a box for filling it in.
  4. Use Save snapshot to keep a version. Snapshots stay in this browser only.
